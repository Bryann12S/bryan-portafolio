## Contexto

Proyecto de tesis desarrollado para la Asociación ASOTAECO: una plataforma web de comercio electrónico para la gestión de ventas e inventario de sus productos textiles. El sitio ya no está en línea.

## Qué hice

- Desarrollo de la plataforma web de comercio electrónico.
- Implementación de los módulos de control de ventas e inventario.
- Desarrollo del backend con Laravel y gestión de la base de datos MySQL.
- Administración y mantenimiento del sistema web.
